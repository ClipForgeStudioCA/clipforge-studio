# ClipForge Studio website

This is a free, one-page static website for ClipForge Studio.

## Before publishing
1. Open `index.html` in a text editor.
2. The contact button is already set to `eddie282002@gmail.com`.
3. If you ever want to change it, replace that address in the `mailto:` link in `index.html`.
4. Save the file.

The portfolio tiles are clearly marked as illustrative concepts, not real client work. Replace them with genuine samples once you have permission to show finished work.

## Publish free with GitHub Pages
1. Sign in to GitHub and create a new public repository named `clipforge-studio` (or another name you prefer).
2. Upload `index.html` to the repository's top level.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub will provide the public `github.io` website address after publishing.

No paid hosting or custom domain is required. A custom domain is optional and costs extra.
